# Hermessenge

SillyTavern 扩展：**运行时提示词注入框架**。旧名「Hermes动态破」。

## 它做什么

在**每一次生成之前**改写提示词，不污染聊天记录。

窗口顶部三个标签：

| 标签 | 作用 |
|---|---|
| **动态破** | 多套配置。往提示词开头 / 末尾各注入一段，并可用「转换管线」就地改写你最新那条消息（替换 / 包装 / 加前后缀 / 交给副模型改写） |
| **roll优化** | 独立的多套「输出方向指令」，以**你自己发的消息**的形态随本轮发送。给关键词可让副模型扩写成规范指令，也可直接手写 |
| **设置** | 副 API（三选一：连接管理器配置 / 使用当前 API / **自定义地址与密钥**）、窗口与侧栏尺寸、悬浮球外观、标记词与拒绝特征 |

悬浮球常驻在角落，可拖动，点开即是状态面板：本轮开关、注入是否生效、标记词命中、判定结果，以及手动改判。

## 安装

1. 在酒馆的「扩展」→「安装扩展」里填本仓库的 Git URL。
2. 若菜单里没有出现，**硬刷新浏览器**（Ctrl+Shift+R / ⌘+Shift+R）。

> ⚠️ 更新后若发现界面没变，**优先硬刷新**。酒馆加载扩展脚本用的是固定 URL，
> 普通刷新不一定能拿到新版本。本仓库的 `manifest.json` 已带 `?ver=<版本>` 参数，
> 正常情况上升级版本即可自动失效缓存。

## 副 API

副模型（用于「模型步」与 roll 页的「让副 AI 优化成指令」）有三种来源：

| 选项 | 说明 |
|---|---|
| 连接管理器配置 | 用酒馆「连接管理器」扩展里已有的配置，密钥由酒馆保管 |
| 使用当前 API | 直接用你正在聊的那个连接 |
| 自定义 | 自己的地址 + 自己的密钥 + 自己的模型，走 OpenAI 兼容格式 |

自定义模式支持两种填法：填 base（`…/v1`）或填完整路径（`…/v1/chat/completions`）。
密钥留空则不发送 `Authorization` 头（本地 Ollama / LM Studio 这类用得上）。
设置页有「测试连接」按钮，可当场验证填得对不对。

## 依赖

无。连接管理器扩展是可选的。

## 隐私

- 选**连接管理器**或**使用当前 API** 时，密钥完全由酒馆保管，**从不经过本扩展**。
- 选**自定义**时，密钥由你手填并随设置存在酒馆里（明文，与酒馆自己存 API Key 的方式一致）。
  界面用掩码显示；错误提示在交给你之前会先擦掉密钥。
- 除你自己填写的那个自定义地址外，本扩展不向任何地方发起网络请求。
