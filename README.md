# Hermessenge

SillyTavern 扩展：**运行时提示词注入框架**。旧名「Hermes动态破」。

## 它做什么

在**每一次生成之前**改写提示词，不污染聊天记录。

窗口顶部四个标签：

| 标签 | 作用 |
|---|---|
| **API管理** | 查看酒馆的连接配置并一键切换；编辑地址与密钥、拉取模型、绑定预设/世界书/角色卡；显示供应商的模型状态 |
| **动态破** | 多套配置。往提示词开头 / 末尾各注入一段，并可用「转换管线」就地改写你最新那条消息（替换 / 包装 / 加前后缀 / 交给副模型改写） |
| **roll优化** | 独立的多套「输出方向指令」，以**你自己发的消息**的形态随本轮发送。给关键词可让副模型扩写成规范指令，也可直接手写。支持维度保持/优化、带旧稿/带上文、全局规范 |
| **判定** | 全局标记词、拒绝特征、上游拦截特征词，以及最近一次判定结果 |

「设置」与「使用说明」收在标题栏右上角（关闭键左侧），点开是窗口内浮层，不再占标签位。

悬浮球常驻在角落，可拖动。点开后是三页，点左侧的 `❁` / `ↀ` / `❀` 切换：

- **`❁` API 切换**：列出全部连接配置，标出当前项，点一条即切。
- **`ↀ` 回答拦截**（默认页）：注入·首 / 注入·尾 / 全局规范各自是否被拦、回复第几段出现拒绝、命中哪条特征，以及捕获到的上游 API 错误。
- **`❀` 重roll优化**：本轮 roll 开关、带旧稿 / 带上文、注入状态，以及旧稿的全部段落。roll 与带旧稿**默认关闭**。

判定支持一键手动改判，人工结论优先于自动检测。

## v1.3.0 更新

- **API 管理**：实时读取酒馆连接配置，一键切换；新建空白配置或复制现有配置为模板。
- **高级设置**（默认折叠）：地址、密钥、拉取模型、预设、世界书、角色卡。
  - 密钥写入酒馆 secret 系统，界面只显示「已保存 / 未设置」，不回显明文。
  - 模型先拉取再从列表选择，不允许手填；拉取结果持久化缓存，下次打开秒显示。
  - 支持「测试连接」查看通断与耗时。
- **模型状态检测**：填写供应商的检测地址后，模型前会显示 7px 状态灯：
  - 🟢 可用 / 🟡 拥堵 / 🔴 不可用 / ⚪ 未检测
  - 支持普通 JSON 状态接口，也支持 Uptime Kuma 状态页（填主页或 `/api/status-page/<slug>` 均可）。
  - 状态页不允许跨域时自动经公共 CORS 代理读取，结果会标注「经公共代理」。
- **悬浮球**新增 `❁` API 切换页，与拦截、roll 完全独立。
- **顶部状态条**只读显示当前 API、模型、预设。

## 安装

1. 在酒馆的「扩展」→「安装扩展」里填本仓库的 Git URL。
2. 若菜单里没有出现，**硬刷新浏览器**（Ctrl+Shift+R / ⌘+Shift+R）。

> ⚠️ 更新后若发现界面没变，**优先硬刷新**。酒馆加载扩展脚本用的是固定 URL，
> 普通刷新不一定能拿到新版本。本仓库的 `manifest.json` 已带 `?ver=<版本>` 参数，
> 正常情况上升级版本即可自动失效缓存。

## API 管理

- **切换**：点配置整行。API、模型、预设、绑定的世界书/角色卡会一起应用。
- **新建**：空白新建，或复制当前选中；每行高级设置里另有「复制为模板」。
- **地址**：写回连接配置的 `api-url`，失焦即保存。
- **密钥**：写入酒馆 secret 系统，连接配置只保存 secret id。留空表示不修改。
- **模型**：先点「拉取模型」，再从下拉里选。拉取与测试连接都走酒馆服务端
  （`/api/backends/chat-completions/status`），与酒馆自带的「获取模型」同源。
- **绑定**：预设写回连接配置；世界书与角色卡存在本扩展的设置里。
  - 世界书是「替换」语义：切换时先清空当前世界书，再启用目标。
  - 角色卡切换会清空当前聊天（酒馆自身行为）。
- **状态检测**：供应商检测地址需返回 JSON。若不允许跨域，会自动经公共代理读取。

## 副 API

副模型（用于「模型步」与 roll 页的「让副 AI 优化成指令」）有三种来源：

| 选项 | 说明 |
|---|---|
| 连接管理器配置 | 用酒馆「连接管理器」扩展里已有的配置，密钥由酒馆保管 |
| 使用当前 API | 直接用你正在聊的那个连接 |
| 自定义 | 自己的地址 + 自己的密钥 + 自己的模型，走 OpenAI 兼容格式 |

自定义模式支持两种填法：填 base（`…/v1`）或填完整路径（`…/v1/chat/completions`）。
密钥留空则不发送 `Authorization` 头（本地 Ollama / LM Studio 这类用得上）。
设置页有「测试连接」按钮，可当场验证填得对不对。

## 依赖

无。连接管理器扩展是可选的。

## 隐私

- 选**连接管理器**或**使用当前 API** 时，密钥完全由酒馆保管，**从不经过本扩展**。
- 在 API 管理里填写密钥时，扩展把它写入酒馆的 secret 系统，界面不回显明文。
- 拉取模型与测试连接由酒馆服务端发起，扩展不接触明文密钥。
- 状态检测地址若不允许跨域，会经公共 CORS 代理（`proxy.corsfix.com` /
  `allorigins.win`）读取；发送给代理的只有你填写的状态页 URL，不包含密钥。
- 除你自己填写的地址外，本扩展不向任何地方发起网络请求。
